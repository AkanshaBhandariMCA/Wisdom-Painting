# Project image filenames

Place your real photos in this folder using these names (used by `index.html`):

## Residential
- `stairs-before.jpg`
- `stairs-after.jpg`
- `living-before.jpg`
- `living-after.jpg`
- `bedroom-before.jpg`
- `bedroom-after.jpg`
- `exterior-after.jpg`

## Commercial
- `office-before.jpg`
- `office-after.jpg`
- `clinic-before.jpg`
- `clinic-after.jpg`
- `warehouse-before.jpg`
- `warehouse-after.jpg`

If a file is missing, the site automatically shows `placeholder.svg`.
